# Working in this repository

- **Never push directly to `main`.** `main` is what Cloudflare deploys to the live site.
  Every change goes on a branch and reaches `main` through a pull request that the owner
  reviews and merges. Open the pull request by default once a change is pushed.
- The site must contain no invented claims about LABMISE (clients, team, prices, results).
  Every statistic needs an entry in the Sources list at the bottom of `public/index.html`.
- See `README.md` for the layout, Cloudflare settings and common edits.
